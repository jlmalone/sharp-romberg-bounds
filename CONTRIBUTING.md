# Contributing

This project welcomes proof review and prior-art review.

## Proof review

Open a proof-audit issue with:

- the theorem, lemma, or equation at issue;
- the precise logical gap or counterexample;
- all hypotheses used in the objection;
- a minimal correction when one is known.

Numerical disagreement is useful diagnostic evidence. A mathematical
counterexample should include exact values or a rigorous limiting argument.

## Prior art

Open a prior-art issue with:

- a stable citation or DOI;
- the exact theorem, proposition, or page;
- a short comparison with the manuscript's error-ratio interval;
- whether the source proves sharpness, arbitrary-mesh validity, or the complete
blend trichotomy.
Shared terminology is not enough to establish anticipation. The comparison
must identify the same hypotheses and conclusion.

## Changes

Keep proof changes separate from editorial changes. Update proof_audit.md when
a mathematical statement changes and novelty_review.md when a source changes
the novelty boundary.
